# e-plantShopping

🌿 Core Features
🍃 Dynamic Catalog Exploration
Curated Selection: An intuitive interface designed for seamless navigation through a diverse collection of indoor botanical specimens.

State-Driven Management: Utilizes efficient state handling to allow users to select and stage items for purchase in real-time.

🛒 Robust Cart Orchestration
Granular Quantity Control: Empowering users with the ability to dynamically increment or decrement item counts within the cart interface prior to finalization.

Real-time Fiscal Calculation: Automated logic to compute individual line items and aggregate the total expenditure, ensuring immediate visual feedback on the user's investment.

Inventory Overview: A centralized summary view providing a comprehensive breakdown of all pending acquisitions and their respective metrics.
